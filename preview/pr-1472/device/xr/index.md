# XR headsets

XR headsets provide head poses and controller or hand input.

The [Quick Start](../../teleop/quick_start.md) covers setup and connection for Meta Quest,
PICO, and Apple Vision Pro. Quest and PICO use the WebXR client; Apple Vision
Pro uses the native sample client. See [Spatial Trackers and Device Data](../trackers/index.md) for the
tracking interfaces and [Body Tracking](../body_tracking/index.md) for body tracking.

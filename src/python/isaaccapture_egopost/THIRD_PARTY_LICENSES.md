# SAM 3D Body (DINOv3 backbone weight initialization)

EgoHand uses a DINOv3 vision backbone whose weights are initialized from
Meta's SAM 3D Body pretrained checkpoint.

**Model-lineage chain:**
SAM 3D Body pretrained weights (DINOv3 architecture)
  → loaded as EgoHand's DINOv3 vision backbone initialization
    → fine-tuned on NVIDIA proprietary synthetic and real-world hand data
      → produces the released EgoHand model weights

SAM 3D Body's pretrained weights are built on the DINOv3 architecture,
which carries its own separate Meta license (see the [DINOv3](#dinov3)
section above).

Source: https://github.com/facebookresearch/sam-3d-body

Model: https://huggingface.co/facebook/sam-3d-body-dinov3

# py-soma-x (SOMA hand/body rig library)

py-soma-x provides the SOMA/MHR hand and body forward-kinematics layer
used by EgoHand for 3D hand mesh generation from predicted pose and shape
parameters.

Source: https://pypi.org/project/py-soma-x/

# Build-time Dependencies (not redistributed)

The Dockerfiles reference a base container image, system packages
(apt-get), and Python packages (pip) that are **fetched by the end user
at build time**. These components are not distributed as part of this
release. See `requirements.txt`, `requirements-dinov3.txt`, and the
Dockerfiles for the declared build dependencies. This release distributes
source code, not built Docker images. Components fetched during a user build
may also be needed at runtime; fetching them at build time does not make them
build-only dependencies.

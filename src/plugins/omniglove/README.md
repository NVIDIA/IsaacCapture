# AgiLink OmniGlove

The Linux plugin publishes OmniGlove finger tracking as OpenXR hands for
Isaac Capture.

Installation, wrist calibration, running, licensing and troubleshooting:
[AgiLink OmniGlove documentation](https://nvidia.github.io/IsaacCapture/main/device/hand_tracking/omniglove.html).

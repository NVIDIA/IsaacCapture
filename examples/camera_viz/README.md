# camera_viz

Camera streaming and visualization with Televiz (`isaaccapture.viz`). View live
cameras, recorded video, or synthetic feeds in an XR headset or desktop window.
Run with locally attached cameras, or stream RTP H.264 from a robot to a workstation.

The [Camera Streaming guide](https://nvidia.github.io/IsaacCapture/main/references/camera_streaming.html)
is the primary documentation for setup, commands, supported cameras, configuration,
controller bindings, deployment, and troubleshooting.

The [guide source](../../docs/source/references/camera_streaming.rst) is included
in this checkout for offline reading and documentation updates. Sample configurations
are in [configs/](configs/).

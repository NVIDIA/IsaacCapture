Limits and retained failures:
This is validation on a prepared host, not a clean-machine installation study.
Host-specific browser test flags bypassed certificate and sandbox enforcement;
the documented customer setup requires a trusted certificate and normal sandbox.
A missing optional dependency in the test harness, an incorrect frame-array
assumption and native Kit process teardown exposed three failed attempts. Those
failures are retained; the latter two led to regression tests and a supervised
observer. The successful stacking wheel differs from the subsequent customer
wheel only by removal of an unused Python import in observer_process.py.
Repeated success/reliability, arbitrary robot/task adapters, real robots,
physical Pico/Quest sensing and current Isaac Capture 1.6 native compatibility
are not qualified. Earlier three-episode footage demonstrates the preceding
preview, not repetition testing of the new session API.
No official SDK release or upstream/main merge is implied.

# Isaac Capture skills

Task-level skills for coding agents that work with Isaac Capture in their own
projects. Each skill is a directory holding a `SKILL.md` in the
[Agent Skills](https://agentskills.io) format.

- [isaac-capture-install](isaac-capture-install/SKILL.md): install the `isaaccapture`
  package into a uv virtual environment, choose its extras, and check that it imports.
- [rebot-orin-setup](https://github.com/NVIDIA/IsaacCapture/blob/main/examples/rebot/SKILL.md):
  bring up a reBot B601-RS arm from a Jetson AGX Orin over its built-in CAN. It lives
  with the reBot example.
